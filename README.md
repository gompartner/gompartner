## 곰파트너

병원, 가게, 기업, 전문직 사무소의 홈페이지와 업무 프로그램을 만듭니다.
업종마다 필요한 기능을 데모로 먼저 만들어 두었습니다. 직접 눌러 보고 비슷하게 주문할 수 있습니다.

### 가격

| 패키지 | 가격 | 기간 | 이런 곳에 맞아요 |
|---|---|---|---|
| 기본 | 299,000원 | 7일 | 가게나 병원을 소개하는 홈페이지 |
| 표준 | 490,000원 | 14일 | 문의와 예약 신청을 받는 홈페이지 |
| 고급 | 990,000원 | 30일 | 자리 예약, 픽업 주문 같은 맞춤 기능이 들어간 홈페이지 |

모든 패키지에 원본 소스와 완료 후 1개월 무상 유지보수가 포함됩니다. 관리자, 자동화, LMS 같은 업무 프로그램은 따로 견적을 드립니다.
